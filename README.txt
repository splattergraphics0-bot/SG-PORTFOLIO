SPLATTER GRAPHICS — COMPLETE PORTFOLIO PACKAGE

This package contains the main portfolio website plus separate galleries for LOGOS, POSTERS and T-SHIRTS, with supplied project images organised into folders. Local Inter font files are included in Fonts/ so the main website typography works without relying on Google Fonts internet access.

FILES / FOLDERS
- index.html, style.css, script.js: main portfolio website
- Logos/index.html + Logos/assets/: logo and branding gallery
- Posters/index.html + Posters/assets/: poster / promotional artwork gallery
- T-SHIRTS/index.html + T-SHIRTS/assets/: T-shirt design gallery
- Fonts/: local font files
- project-2.html: existing project detail page

HOW TO USE
1. Extract this ZIP while preserving all folders.
2. Open index.html locally to preview.
3. To publish on GitHub Pages, upload the contents of this folder into the repository root, keeping the folder names and structure unchanged.
4. Check the published site and contact links after upload.

NOTE
The image galleries include portfolio assets available in this working session. If you have other logo/poster files not uploaded here, add them to the corresponding assets folder and add an image card to that gallery page.
